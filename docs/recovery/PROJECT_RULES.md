# Regras estáveis do projeto

- Trabalhar evidence-first e priorizar fontes primárias.
- Claims `DERIVED` devem ser conservadores, auditáveis e possuir `derived_from` válido.
- Não tratar campos semanticamente diferentes como comparáveis automaticamente.
- Nunca inventar fatos, preço, estoque, rating, reviews, medições ou experiência prática.
- PageSpecs são a fonte editorial; Astro é o renderer estático.
- Preservar origem, licença e registro das imagens.
- Automatizar somente depois de observar uma dor real e manter validações explícitas.
- Monetização só entra depois de gate editorial humano.
- Commit não autoriza push; publicação e push exigem autorização humana explícita.
- Publicação automática permanece proibida.
- Build e QA aplicáveis devem passar antes de concluir uma implementação.
