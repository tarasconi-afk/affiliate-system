## Diretrizes Seguidas

1. **Nenhuma imagem de terceiros foi copiada** - Todos os visuais são SVGs criados especificamente para este projeto
2. **Nenhuma foto de produto real** - Evitamos usar imagens de marketplaces ou sites de fabricantes sem permissão clara
3. **Disclaimers incluídos** - Todas as ilustrações indicam que são representativas, não fotos reais
4. **Sem logos oficiais** - Não reproduzimos marcas registradas visuais
5. **Apenas texto e formas geométricas** - Elementos básicos que não violam propriedade intelectual

## Próximos Passos (se necessário)

Para melhorar as imagens no futuro:
- Buscar imagens oficiais com permissão explícita de uso

## Atributos de Imagem

Todas as imagens incluem:
- `alt` text descritivo
- `width` e `height` definidos para evitar layout shift
- Formato SVG para tamanho mínimo e escalabilidade
