# Ferramenta Clara

Projeto pessoal de MVP SEO/afiliados para o mercado brasileiro.

Marca pública:  
Ferramenta Clara

Domínio:  
https://ferramentaclara.com.br

## Princípios

- Astro é o renderer estático, não o cérebro/orquestrador do sistema.
- Conteúdo editorial é estruturado em PageSpecs.
- Evidências são parte central do sistema.
- Nunca inventar fatos, preços, avaliações, medições, testes ou experiência prática.
- Nunca alegar hands-on quando não houve teste real.
- Priorizar fontes primárias.
- Preservar os tipos de evidência existentes.
- Dados derivados devem continuar auditáveis.
- Não adicionar frameworks frontend pesados sem necessidade.
- JavaScript mínimo.
- Performance, SEO, clareza editorial e rastreabilidade são prioridades.
- Não alterar arquitetura sem necessidade explícita.
- Não liberar indexação sem instrução explícita.
- Não fazer deploy automaticamente sem que a tarefa peça.
- Nunca fazer force push.
- `npm run build` deve passar antes de considerar uma implementação concluída.

## Fluxo padrão de execução

1. Ler somente os arquivos relevantes.
2. Explicar brevemente o plano.
3. Fazer a menor alteração necessária.
4. Executar validações/build.
5. Corrigir erros causados pela alteração.
6. Mostrar resumo e arquivos modificados.
7. Não fazer commit até receber autorização explícita.
