Tratamento aplicado

Os arquivos originais são preservados para rastreabilidade. No site, as imagens podem ser redimensionadas, convertidas para WebP e enquadradas por CSS para adequação ao layout. Não removemos marcas presentes nas fotografias nem apresentamos uma imagem como um SKU específico quando isso não é comprovado pela fonte.
